# otp-watch

Внешний сторож сайта [otpustite.com](https://otpustite.com). Раз в 5 минут GitHub Actions
открывает `/api/health` и, если сайт не отвечает дважды подряд, пишет владельцу в Telegram.

Сторож на самом сервере ловит поломки приложения, диска и памяти, но о собственной смерти
сервер сообщить не может — для этого и нужна проверка снаружи.

Секреты репозитория: `TG_TOKEN` (токен бота), `TG_CHAT` (чат владельца).
